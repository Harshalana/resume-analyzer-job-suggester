# CareerCraft AI - Resume Analyzer & Job Suggester

CareerCraft AI is an intelligent, full-stack resume analysis, ATS scoring, and career advisory engine.

## Features
- **Multi-Format Resume Ingestion**: Upload PDF, Word (DOCX), or paste text directly.
- **ATS Compatibility Scoring**: Evaluates section completeness, impact metrics, action verbs, and keyword density.
- **Actionable Suggestions**: Specific bullet-point rewrites following the STAR/XYZ methodology.
- **Skill Gap & Job Matching**: Matches candidate profiles against 40+ high-demand tech roles with learning roadmaps.
- **Custom Job Description Matcher**: Compare any target job posting to get an exact match breakdown.
- **AI Cover Letter & Interview Generator**: Generates tailored cover letters and interview questions.
